# Customer-Segmentation--RFM-Analysis in Excel
This project peforms an RFM analysis to segment customers based on their purchasing behaviour.
The analysis helps identify valuable customer segments targeted to improve engagement, retention and revenue.

RFM is a method used to identify, analyse and segment customers based on their purchasing history.
Recency means how recent was the last purchase by a customer.
Frequency means the number of transactions a customer made.
Monetary means the sum of all revenue generated by a customer.

Objective
To analyze customer value and behaviour using RFM metrics and segment customers into actionable groups for better
marketing and decision making.

Data Sources
Customers- customer details
Products - Product information.
Orders - Transaction history
The three datasets were combined using xlookup and pivot tables for analysis.

Tools And Techniques
Microsoft Excel
Pivot tables
Xlookup
Rank.Percentile/Round
IFS(for scoring and segmentation)

Customers were scored on each metric, combined for an overall RFM score, and assigned to meaningful segments.
